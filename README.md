## `> description`

This file contains a numeric wordlist generated from **0000 to 9999**. Each number is zero-padded to maintain a fixed length of 4 digits.

## `> usage`

This wordlist can be used for:

- Testing password strength
- Learning about authentication systems
- Security research in controlled, authorized environments

> ⚠️ Use this only on systems, apps, or devices you own or have explicit permission to test. Do not use it against accounts or devices you don't own or haven't been authorized to test.

## `> format`

- Total entries: 10,000
- Range: `0000` → `9999`
- Each entry is on a new line

```bash
0000
0001
0002
...
9999
```

## `> installation`

Clone the repository:

```bash
git clone https://github.com/ANANNOCHOWDHURY/bruteforce.git
```

Enter the directory:

```bash
cd bruteforce
```

Give the script execute permission:

```bash
chmod +x bruteforce.sh
```

Run the script:

```bash
./bruteforce.sh
```

OR

```bash
bash bruteforce.sh
```
